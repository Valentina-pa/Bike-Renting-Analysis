Bike renting analysis is an analysis for both casual member and registered member behavior when they rented bike for two years (2011-2012) in Washington DC. 
In this dataset used, there's some feature like :\
a. Datetime : hourly date and timestamp\
b. Season : Code representing the meteorological season. 1 : Winter, 2: Spring, 3: Summer, 4:Fall\
c. Holiday : Code 0 for not public holiday and code 1 for public holiday\
d. Workingday : 0 for weekend and 1 workday\
e. Weather : code for categorical status. 1: Clear, 2: Mist, 3: Light Snow/Rain, 4: Heavy Rain\
f. Temp and atemp : actual temperature and feels like temperature in celcius\
g. Humidity : relative humidity percentage\
h. Casual : count of non registered member\
i. Registered : count of registered member\
j. cnt : total member\
